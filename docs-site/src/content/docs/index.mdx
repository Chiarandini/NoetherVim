## Get going

```bash
mkdir -p ~/.config/nvim
curl -fLo ~/.config/nvim/init.lua https://raw.githubusercontent.com/Chiarandini/NoetherVim/main/init.lua.example
nvim
```

:::caution
If you already have a Neovim config, [back it up
first](/noethervim/start/install/). The command above writes to
`~/.config/nvim/init.lua`.
:::

Then read [your first session](/noethervim/start/first-session/), or jump
straight to the [onboarding guide for
mathematicians](/noethervim/start/mathematicians/) if that is what brought you
here.
